Have you ever wished you could go back in time in a strategy game and fix a mistake you made on turn #1? Get a chance to counter that rush, or counter rush before you got wiped? What about going back in time and having an army parked exactly where you now know the opponent’s secret base is? What if you could go back?

If you think about it, an real-time strategy game is a simulation that is being repeatedly interrupted by players. If you replayed the same inputs over time on the same sim, the game would execute identically. At any point, both players could walk away and the game would keep running for a while, as units keep getting built and attacking until the map runs out of resources.

Atemporal is my attempt at making a strategy game set outside of time. Every round is a timeline, where the game executes from beginning to end. Every player sees how the new reality went and picks a single point in time to change what orders their units execute. Build a new factory, attack a new area, or retarget a missile. When all players have locked their moves, see how the new timeline goes. First player to win 5 timelines wins the game.

Note: This is very much an experiment. All of the code and most of the docs is all chatbots. The game is intentionally simple and minimal. I was mostly curious to see if this mechanic makes a game that is even playable. I think it’s pretty fun but am very curious to hear what others think.

Also this is open source if you want to play with the code or write a better bot.
